# Spec Delta

## ADDED Requirements

### Requirement: 个人知识库接地出题

当用户发起首页出题且个人知识库存在已就绪文档时，系统 SHALL 允许出题 Agent 检索当前用户的个人知识库，并基于真实分块生成题目、选项、答案与讲解。题库 SHALL 在参考来源中标注知识库来源（文档名、页码、分块摘要、相关度）并将 grounded 置为 true。系统 MUST NOT 编造知识库中不存在的事实或出处。

#### Scenario: 知识库内容支撑出题

- **WHEN** 用户发起首页出题，个人知识库存在与主题相关的已就绪分块
- **THEN** 生成的题目与讲解依据这些分块，参考来源包含知识库文档名与分块摘要，grounded 为 true

#### Scenario: 知识库无相关内容

- **WHEN** 个人知识库没有与主题相关的分块
- **THEN** 系统不因知识库为空直接失败，Agent 可改用联网检索或回退到未接地出题

#### Scenario: 知识库出处可追溯

- **WHEN** 题库引用了个人知识库内容
- **THEN** 每条知识库来源的文档名、页码与分块摘要来自真实检索结果，可按文档与分块定位

#### Scenario: 仅检索本人知识库

- **WHEN** 用户发起首页出题
- **THEN** 知识库检索结果仅来自当前用户的文档，不包含其他用户的文档内容

### Requirement: 文档一键闯关

当用户从文档卡片点击“开始闯关”时，系统 SHALL 创建仅检索该文档的出题任务，主题取自文档名，默认 5 题、混合难度，MUST NOT 使用联网来源或其他文档。题库 SHALL 基于该文档的真实分块生成并在来源中标注文档出处；若文档在任务执行时已失效、未就绪或无可用分块，任务 SHALL 失败并返回可读原因，MUST NOT 用泛化知识生成题目。

#### Scenario: 文档可用时一键出题

- **WHEN** 用户点击一个已就绪文档的“开始闯关”
- **THEN** 系统创建以该文档为主题的异步出题任务，题目依据该文档分块，来源包含该文档出处，且不使用联网来源

#### Scenario: 文档失效时明确失败

- **WHEN** 任务执行时所选文档已被删除、未就绪或不属于当前用户
- **THEN** 任务失败并提示文档不可用，请重新上传，不生成与文档无关的题目

#### Scenario: 文档无可用分块

- **WHEN** 所选文档没有可检索的分块
- **THEN** 任务失败并提示文档内容不可用，不退回泛化出题

#### Scenario: 默认出题参数

- **WHEN** 用户从文档卡片一键开始闯关且未额外设置
- **THEN** 任务使用 5 题、混合难度，并复用现有生成中、轮询与答题流程

### Requirement: 首页出题 Agent 自主路由

当用户未指定文档范围时，出题 Agent SHALL 在个人知识库有可用文档时同时具备知识库检索与联网搜索/网页抽取能力，并依据主题性质与检索结果自主决定使用哪种来源；系统 MUST NOT 以固定顺序强制只用某一种来源。知识库无相关内容时 Agent MAY 改用联网检索；需要最新公开信息时 Agent MAY 使用联网检索。

#### Scenario: 私有主题走知识库

- **WHEN** 用户输入的是个人知识库覆盖的内部或私有主题
- **THEN** Agent 使用知识库检索结果出题

#### Scenario: 公开时效主题走联网

- **WHEN** 主题依赖最新公开信息且个人知识库无覆盖
- **THEN** Agent 使用联网检索获取事实后出题

#### Scenario: 混合使用来源

- **WHEN** 主题同时需要私有资料与公开信息
- **THEN** Agent 可同时使用知识库分块与联网结果，并在参考来源中分别标注

#### Scenario: 不编造来源

- **WHEN** 知识库与联网均未返回可用信息
- **THEN** 系统按既有降级链路出题，grounded 为 false，参考来源为空，不编造任何出处

### Requirement: 无可用文档时保持原有行为

当用户未指定文档范围且个人知识库没有已就绪文档时，出题 SHALL 保持现有联网接地与未接地降级链路的行为不变，MUST NOT 因知识库功能引入而改变题库结构、grounded 语义或来源展示规则。

#### Scenario: 无文档且联网可用

- **WHEN** 个人知识库没有已就绪文档且联网接地可用
- **THEN** 出题沿用现有联网检索行为，不访问个人知识库

#### Scenario: 无文档且联网不可用

- **WHEN** 个人知识库没有已就绪文档且联网接地未配置或失败
- **THEN** 出题沿用现有未接地降级链路，行为与知识库功能上线前一致

## MODIFIED Requirements

### Requirement: 参考来源透出

当出题经过联网检索、网页抽取或知识库检索接地时，系统 SHALL 返回参考来源列表（sources）。联网/网页来源每条至少包含标题与 URL；知识库来源每条至少包含文档名、分块摘要、相关度与来源类型，URL 可为空。参考来源 SHALL 取自真实检索、抽取或知识库分块结果并按来源去重，MUST NOT 由模型凭空生成。

#### Scenario: 返回参考来源

- **WHEN** 出题成功经过联网接地
- **THEN** 响应包含非空的参考来源列表，每条含来自真实检索/抽取结果的标题与 URL

#### Scenario: 返回知识库来源

- **WHEN** 出题成功引用个人知识库分块
- **THEN** 响应包含知识库来源，每条含真实文档名、分块摘要、相关度与来源类型

#### Scenario: 无可用检索结果不编造

- **WHEN** 检索未返回任何可用结果
- **THEN** 参考来源列表为空，且系统不编造任何 URL、文档名或标题

### Requirement: 闯关页展示参考来源

前端 SHALL 在闯关页提供参考来源列表供用户查看；联网/网页来源展示标题与可点击链接，知识库来源展示文档名、页码、分块摘要与来源标识。未接地或来源为空时不展示来源区域，且不影响答题与讲解体验。本次解读（interpretation）由后端 Agent 自行判定并随题库保存，用于聚焦出题领域，不在前端展示。

#### Scenario: 接地时展示来源

- **WHEN** 题库经过联网接地且含参考来源
- **THEN** 闯关页可查看参考来源列表，联网来源以标题与链接展示

#### Scenario: 知识库接地时展示来源

- **WHEN** 题库引用了个人知识库分块
- **THEN** 闯关页展示文档名、页码、分块摘要与知识库来源标识，不提供无效链接

#### Scenario: 未接地时隐藏

- **WHEN** 题库未接地或参考来源为空
- **THEN** 闯关页不展示参考来源区域，答题与讲解照常呈现
